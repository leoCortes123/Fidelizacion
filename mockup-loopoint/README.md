# Mockup Gráfico Interactivo — Loopoint Multi-Rol

Esta carpeta contiene el prototipo gráfico e interactivo de la reorganización propuesta para **Loopoint**, aislado del código productivo (`fidelizacionWeb/`).

## Archivos
- `index.html` — Aplicación de mockup autocontenida con selector superior de roles (**Administrador**, **Encargado**, **Cliente**) y flujos interactivos.
- `loopoint-coin.png` — Activo pixel art de la moneda oficial de Loopoint.

## Cómo visualizarlo
Puedes abrir `index.html` directamente en cualquier navegador o servir la carpeta localmente:

```bash
cd mockup-loopoint && npx serve .
```
